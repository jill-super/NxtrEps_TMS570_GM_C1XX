## Terms

| Term | Meaning |
| --- | --- |
| SW-C | AUTOSAR Software Component (`Ap_*` application, `Sa_*` sensor/actuator, `Cd_*` complex driver) |
| MDD | Module Design Document (per-module `*_MDD.docx`, converted under each module page) |
| RTE | Run-Time Environment (Vector-generated; `GenDataRte/`, `utp/contract/`) |
| BSW | Basic Software — Vector MICROSAR stack under `SwProject/Source/BSW/` |
| MCAL | Microcontroller Abstraction Layer (peripheral drivers for TMS570) |
| CDD | Complex Device Driver (`Cd_*`, motor-control and power-stage drivers) |
| MICROSAR | Vector's AUTOSAR basic-software implementation |
| DaVinci | Vector configuration/generation tooling (`.arxml`, `.dcf`, `.dcb`, `.tt` templates) |
| NvM / Fee / Fls | NVRAM manager / Flash-EEPROM emulation / Flash driver (memory stack) |
| Tessy | Unit-testing tool; artefacts live in each module's `utp/` folder |
| QAC | PRQA static-analysis tool; project config in `QAC/` |
| ASIL D | Highest Automotive Safety Integrity Level (ISO 26262); this EPS is developed to ASIL D |
